# Mac Desktop Edition

一个独立、可直接打开的 Windows 桌面视觉原型。它以 macOS 的信息层级、Dock 放大、顶部菜单栏、窗口组、玻璃材质和专注状态为参考，但不包含 Apple 标志、macOS 代码、系统文件或受限资源。

## 打开方式

直接打开 `index.html`，或在仓库根目录启动任意静态服务器后访问：

```powershell
Start-Process .\mac-desktop-edition\index.html
```

## 已实现交互

- 顶部菜单、应用启动器、控制中心和正在播放卡片。
- 左侧窗口组切换三种桌面窗口。
- macOS 风格交通灯：关闭、最小化与缩放状态反馈。
- 底部 Dock 的连续放大效果和悬停提示。
- `F` 键或“专注”按钮切换低干扰布局。
- 实时时钟，所有状态只存在浏览器内存，刷新后还原初始原型状态。

## 安全边界

该目录是 GitHub 仓库内的独立静态原型。它不读取、不写入、不启动以下任何内容：Windows 注册表、MyDockFinder、Lively Wallpaper、Seelen UI、现有组件状态、启动项、个人文件、音乐记录或桌面布局。

背景引用的是本仓库已经发布的无个人内容深空预览图，不会读取或复制本机正在使用的壁纸。
